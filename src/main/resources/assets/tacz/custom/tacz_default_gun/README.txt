This bundled pack contains the ten BUJIDAO firearms and four dedicated scopes.
TACZ ammunition, common attachments, sounds, scripts and workbench assets remain
as shared dependencies. Original TACZ firearms are no longer registered.

Gun IDs use bujidao: (for example bujidao:ar_01 and bujidao:hg_3).
Client resources: assets/bujidao/. Gameplay configuration: data/bujidao/.
Paper exports editable guns/bujidao/, ammos/tacz/, attachments/, recipes/ and
attachment_tags/ directories. Existing Paper directories are authoritative:
replace the complete configuration snapshot to remove previously exported guns.

For deployment, presets and special effects, see docs/bjd-gunpack.md in the project.
The MOD refreshes this bundled folder when its fingerprint changes. Back up any
manual edits, or enable DefaultPackDebug in the version's tacz-pre.toml before
editing the exported client copy. Existing exports are backed up to tacz_backup.

Custom assets: supplied BUJIDAO project pack.
Shared TACZ resources retain their original credits and license.
